El autotransformador se representa mediante una relación ideal Vs = aVp; no se simulan saturación, límites de V/f, pérdidas magnéticas, pérdidas de cobre ni transitorios de conmutación. La fuente de frecuencia variable es un bloque independiente. No construyas este esquema directamente con tensión de red o protoboard. El simulador no certifica seguridad de hardware real.
